# Development

## Purpose

This section defines the engineering practices, development standards, and collaboration guidelines used throughout the School Management System.

Its purpose is to establish a consistent approach to software development, ensuring that all contributors—both human developers and AI assistants—follow the same engineering principles and project conventions.

Unlike the previous sections, which describe the system itself, this section focuses on how the system should be developed, maintained, and evolved.

---

# Contents

This section currently includes:

- **Development Workflow** — Defines the project's development process and AI collaboration guidelines.
- **Coding Standards** — Establishes general coding principles and style conventions.
- **Git Workflow** — Defines repository, branching, and commit practices.
- **Project Conventions** — Documents project-wide development conventions.
- **Code Review** — Describes the code review process and expectations.
- **Documentation** — Defines how technical documentation should be created and maintained.
- **Dependency Management** — Explains how project dependencies are introduced and maintained.
- **Local Development** — Provides guidance for setting up and running the project locally.

Additional engineering practices may be documented as the project evolves.

# Responsibilities

This section is responsible for:

- Defining engineering practices.
- Establishing development standards.
- Documenting collaboration workflows.
- Promoting consistent coding practices.
- Supporting AI-assisted development.
- Defining project-wide engineering conventions.

This section intentionally avoids describing business rules, software architecture, or implementation details, which are documented elsewhere in the Engineering Handbook.
