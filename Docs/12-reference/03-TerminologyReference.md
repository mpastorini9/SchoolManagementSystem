# Terminology Reference

## Purpose

This document provides a quick reference to the official terminology used throughout the School Management System.

Its purpose is to help contributors locate the project's authoritative terminology without duplicating definitions already documented elsewhere.

The official glossary remains the single source of truth for all business and technical terms.

---

# Official Terminology

All business and technical terminology used throughout the project should follow the definitions established in the project's Glossary.

Contributors should use consistent terminology across:

- Documentation
- Source code
- API contracts
- Architecture
- Product discussions

Using a common vocabulary improves communication and reduces ambiguity.

---

# Single Source of Truth

Terminology should be defined in only one location.

New concepts should be added to the Glossary rather than documented independently in multiple places.

If terminology changes over time, the Glossary should be updated accordingly.

---

# Consistency

Every business and technical concept should have a single official name throughout the project.

Contributors should avoid introducing alternative names or synonyms that may create confusion.

Consistency is more valuable than individual naming preferences.
