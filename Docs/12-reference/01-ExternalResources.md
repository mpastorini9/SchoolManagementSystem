# External Resources

## Purpose

This document provides references to external resources that support the development and maintenance of the School Management System.

Its purpose is to centralize links to official documentation and trusted learning resources without duplicating information already maintained by external organizations.

The Engineering Handbook documents the project.

External resources document the technologies used by the project.

---

# Official Documentation

Whenever possible, contributors should consult the official documentation provided by the maintainers of each technology.

Official documentation should always be considered the primary source of technical reference.

---

# Using External Resources

External documentation should complement the Engineering Handbook rather than replace it.

Project-specific decisions, business rules, and architectural principles should always be documented within this repository.

General technology documentation should remain in its official source.
