# Reference

## Purpose

This section provides supporting reference material for the School Management System.

Its purpose is to centralize useful reference information that complements the rest of the Engineering Handbook without duplicating existing documentation.

Unlike previous sections, which explain concepts, principles, and engineering practices, this section serves as a quick reference for contributors during development and maintenance.

---

# Contents

This section currently includes:

- **External Resources** — References to official documentation and external learning resources.
- **Technology Stack** — Overview of the technologies currently used by the project.
- **Terminology Reference** — Quick reference to the project's official terminology.
- **File Structure** — Overview of the repository organization.
- **Document Index** — Complete index of the Engineering Handbook.

Additional reference material may be added as the project evolves.

---

# Reading Order

Reference documents are intended to be consulted when needed rather than read sequentially.

Contributors should use the document that best matches the information they are looking for.

---

# Responsibilities

This section is responsible for:

- Providing quick reference information.
- Organizing supporting documentation.
- Centralizing external references.
- Improving documentation discoverability.
- Supporting contributor productivity.

This section intentionally avoids duplicating information already documented elsewhere in the Engineering Handbook.

This section complements the entire Engineering Handbook.
