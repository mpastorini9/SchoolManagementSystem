# Technology Stack

## Purpose

This document provides an overview of the technologies currently used throughout the School Management System.

Its purpose is to establish a single reference for the project's official technology stack, helping contributors understand the tools, frameworks, and platforms that support the application.

Technology choices may evolve over time as the project grows.

---

# Design Principles

Technology selection follows the project's engineering principles.

Technologies should be:

- Reliable
- Maintainable
- Well supported
- Appropriate for the project's size and complexity
- Consistent with the long-term product vision

New technologies should only be adopted when they provide clear long-term value.

---

# Backend

Current backend technologies include:

- ASP.NET Core Web API
- .NET
- Entity Framework Core
- C#

These technologies provide the foundation for the application's business logic and API.

---

# Frontend

Current frontend technologies include:

- React
- Vite
- JavaScript

Additional frontend technologies may be incorporated as the application evolves.

---

# Database

Current database technologies include:

- SQL Server
- Entity Framework Core Migrations

Alternative database technologies may be evaluated in the future if business requirements justify their adoption.

---

# API

Current API technologies include:

- REST
- OpenAPI (Swagger)
- JSON

These technologies define how external applications communicate with the platform.

---

# Development

Current development technologies include:

- Git
- GitHub
- Markdown

Additional engineering tools may be introduced as the development process evolves.

---

# Future Evolution

The technology stack is expected to evolve throughout the lifetime of the project.

Technology changes should be:

- Intentional
- Documented
- Consistent with the project's architecture
- Supported by clear engineering or business benefits

Technology adoption should never compromise the maintainability of the platform.
